# Codex Studio 0.1.1

## Bundled theme library

- Ships all 130 theme packages from the managed Codex library inside the app bundle.
- Seeds missing bundled packages into `~/Library/Application Support/CodexDreamSkinStudio/themes` on first launch while preserving existing local themes.
- Future packages added under `Resources/ThemePacks` are included automatically in the next release build.

## Apply reliability

- Ships the Codex Dream Skin apply runtime inside the app bundle.
- Installs the bundled runtime only when a managed runtime is not already present.
- Keeps the existing apply-and-verify flow and avoids reporting success until Codex confirms the requested theme.

## Packaging

- Updated the app bundle assembly to include the complete theme library and runtime.
- Retained provenance and licensing guidance for bundled theme packages and the upstream runtime in `ATTRIBUTIONS.md`.
