# Codex Studio 0.1.17

- New rounded glass app icon with layered artwork and a luminous studio sparkle.
- Existing Codex Studio pins in DockDoor Pro receive a content-versioned custom-icon path when Studio launches after updating, avoiding reuse of the previous image URL.
- Preserves unrelated DockDoor pins, profile order, settings, and the separate themed Codex launcher icon.
- Build staging now detects changed app-icon bytes instead of silently reusing an older local asset cache.

If DockDoor Pro retains an in-memory image until relaunch, quit and reopen DockDoor Pro once. The app does not forcibly restart DockDoor or clear its settings.
