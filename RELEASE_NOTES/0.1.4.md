## DockDoor relaunch hardening

- Repairs the per-user theme persistence monitor when the DockDoor helper is launched directly.
- Persists the actual loopback port selected after a cold Codex restart, including non-default ports.
- Makes the persistence agent report load failures instead of silently appearing successful.
- Labels the DockDoor helper `Codex Studio (Themed)` so it is distinguishable from the stock Codex shortcut.
- Keeps the bundled runtime version aligned with the release that installed it.
