# Codex Studio 0.1.14

## A steadier local studio

- Re-checks the Codex runtime whenever the app returns to the foreground, so sleep, fast user switching, or a Codex update cannot leave the status surface stale.
- Prevents overlapping local catalog scans and guards asynchronous theme apply and restore results against stale updates.
- Adds a privacy-conscious Diagnostics panel with copyable runtime/catalog details and a shortcut to the local support folder.
- Adds stable accessibility targets for sidebar destinations, theme actions, search, category filtering, and diagnostics controls.
- Corrects the accessibility descriptions for Favorites and Recently used so their counts describe the right collection.
- Preserves the contained adaptive Canvas glow, offline Apple wallpaper library, Favorites and Recent collections, unified window chrome, DockDoor relaunch recovery, and Sparkle updates.
