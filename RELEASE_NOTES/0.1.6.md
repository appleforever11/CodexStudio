# Codex Studio 0.1.6

## Studio interface overhaul

- Reworks the app shell with a calmer Apple-inspired split-view workspace.
- Refreshes Canvas, Themes, Live Lab, Library, and Settings with native-feeling materials, controls, typography, and spacing.
- Expands the local theme library presentation with wider cards, clearer categories, and more comfortable gallery density.
- Includes the current official Apple macOS, iOS, and iPadOS wallpaper shelves in this user-directed offline release artifact; each pack retains its local-only provenance record and attribution.

## Sidebar and window layout

- Reserves the native titlebar area so the Studio brand never collides with traffic lights.
- Separates scrollable navigation from the persistent runtime and themed-Codex actions.
- Pins the connection status and launch action to the bottom of the sidebar at any window height.
- Keeps the build launcher from replacing a live executable, preventing stale temporary-bundle signature races during rebuilds.

## Update delivery

- Keeps the internal Sparkle build number monotonic with the existing release feed so 0.1.6 is offered normally by Check for Updates.
