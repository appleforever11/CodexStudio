# Codex Studio 0.1.2

## DockDoor update recovery

- Bundles the DockDoor-compatible `Codex Themed.app` launcher and the Codex Studio icon.
- Installs or upgrades the launcher without replacing an unrelated app with the same display name.
- Starts the official signed Codex app through the managed theme engine, keeps the helper alive for DockDoor, and repairs a stock Codex launch after an app update.
- Refreshes an existing theme persistence monitor after a runtime migration so it uses the updated repair logic.

## Sparkle migration

- Upgrades an older managed theme runtime atomically when the bundled runtime version is newer, while preserving a newer local runtime.
- Carries the launcher and runtime migration to existing installations through the Sparkle update path.
- Continues to ship the complete bundled theme library and apply-and-verify flow.
