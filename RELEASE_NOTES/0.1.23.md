# Codex Studio 0.1.23

## Theme relaunch recovery

- Fixes the ChatGPT quit → CDP relaunch sequence used when applying a theme.
- Waits for the signed ChatGPT main process and verifies `/json/version` before starting the injector.
- Uses exact ChatGPT executable identity checks so orphaned helper processes and reused PIDs cannot trigger a restart loop.
- Recovers to a normal ChatGPT launch when themed startup or renderer verification fails.
- Disables persistence and clears stale active-theme state after a failed apply.
- Adds a safe CDP-only relaunch diagnostic that never starts the injector or changes theme state.

Existing themes, local artwork, and user data are preserved.
