# Codex Studio 0.1.12

## Unified Studio chrome and saved themes

- Replaces the duplicated native/in-app top bars with one continuous macOS window header that keeps the traffic lights and window dragging intact.
- Aligns the sidebar and Canvas to the full window surface so the brand, navigation, connection footer, and content no longer inherit the old top or bottom insets.
- Adds a persistent Favorites collection with a dedicated sidebar destination, independent star controls, saved-state accessibility labels, and instant local switching.
- Includes the offline Apple macOS, iOS, and iPadOS wallpaper shelves in the signed bundle so a fresh install has its visual library without waiting for iCloud or a network fetch.
- Ships the refreshed rounded Codex Studio icon in the app bundle and keeps the existing themed Codex and DockDoor launcher icons unchanged.
- Preserves the bundled theme catalog, theme application flow, DockDoor relaunch behavior, and Sparkle update feed.
