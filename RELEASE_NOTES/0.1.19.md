# Codex Studio 0.1.19

## Abstract wallpaper library

- Added on-demand MoeWalls Abstract browsing with larger artwork cards, source-aware quality choices, and a crash-safe WebKit animation preview.
- Added sorting by Recommended, Newest, Name, Largest preview, and Recently viewed.
- Added filters for All wallpapers, Imported, Favorites, and Large previews, with persistent selections and local status badges.
- Added a bounded recently-viewed list and cached local-library status checks so the gallery stays responsive as the catalog grows.
- Kept the catalog source-only: wallpapers remain downloaded only when the user imports one, avoiding release-bundle bloat.

## Reliability

- Improved unavailable-source errors so failed downloads return to the quality sheet with actionable guidance and preserve the attempted choice.
- Verified the new Abstract controls, filtering counts, alphabetical ordering, and sort/filter persistence after relaunch.
