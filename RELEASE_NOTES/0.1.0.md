# Codex Studio 0.1.0

Codex Studio is a new native macOS theme studio for shaping and applying an art-directed Codex workspace.

## Highlights

- Adds the responsive Codex Studio shell with Canvas, Themes, Library, Settings, and Live Editor workspaces.
- Adds a curated visual library plus discovery of the local managed Codex theme collection.
- Adds a live emulated Codex canvas with surface selection, palette controls, opacity, softness, and corner-radius tuning.
- Keeps theme application explicit and verifies the requested runtime state after the switch completes.
- Adds the original Codex Studio glass-aperture app icon.
- Adds Sparkle 2.9.6 with signed GitHub release-feed support.

## Compatibility

- Apple Silicon.
- macOS 14 or later.
- Existing local Codex theme runtime installation required for applying managed themes.
