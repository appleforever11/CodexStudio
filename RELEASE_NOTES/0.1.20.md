# Codex Studio 0.1.20

## Capability-aware runtime

- Aligns the injector's reported version with the bundled `DreamSkinRuntime/VERSION` file so shell, payload, and renderer diagnostics share one source of truth.
- Adds explicit DevTools target classification so the main Codex page, avatar composition surface, external pages, and embedded webviews stay separate.
- Adds a read-only Codex capability check for the installed app version/build, loopback renderer, bundled Node and CLI versions, app-server support, and declared feature flags.
- Keeps runtime inspection bounded and local-only; it never attaches to a renderer, starts app-server, or reads account content.

## Studio polish

- Adds a Connection settings capability panel with clearer health, renderer, package, and feature status.
- Makes the navigation rail opaque so the Codex window behind Studio cannot bleed through its labels and selection states.
- Extends safe diagnostics with compatibility and renderer-target context without including prompts, artwork bytes, or credentials.
