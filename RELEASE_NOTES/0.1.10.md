## Modular runtime and polished Studio UI

- Splits the theme injector, renderer, Dream Skin CSS, import/publish pipeline, macOS runtime scripts, theme library service, live editor, and validators into focused modules while preserving their existing behavior.
- Gives Codex Studio a more native macOS surface with adaptive appearance colors, clearer spacing and hierarchy, consistent panel and control treatment, stronger pressed and hover states, and reduced-motion support.
- Adds clearer live-editor controls, a wider inspector, accessible preview-mode labeling, and explicit loading and empty states for theme shelves and the local library.
- Keeps theme injection, runtime verification, theme publishing/importing, CSS validation, package validation, DockDoor support, and Sparkle updates intact.
