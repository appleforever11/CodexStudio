# Codex Studio 0.1.18

## A more immersive Studio

- Larger Canvas artwork, wallpaper-derived ambient color, glass controls, and a selection inspector on wider windows.
- Platform shortcuts in Explore, clearer navigation, and a larger bottom-anchored preview.
- Settings organized into General, Connection, Library, and Recovery.
- Tighter DockDoor artwork for a more consistent icon footprint.

## Reliability and maintainability

- Separate catalog, library, navigation, editor, and runtime responsibilities; smaller editor and Settings components.
- Catalog refreshes preserve edits to the selected theme.
- Bounded script timeouts and output collection prevent inherited pipes or ignored termination from holding an operation open indefinitely.
- Runtime 1.9.2 reconciles completed operations after renderer setup and retries status delivery.
- Runtime version changes refresh the build cache automatically.
- Local Apple wallpaper packs remain available offline.
