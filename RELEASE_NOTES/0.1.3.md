# Codex Studio 0.1.3

## Reliable themed relaunches

- Applying a theme now enables the managed per-user relaunch monitor, so launching the stock Codex app after `⌘Q` automatically restores the verified theme.
- The DockDoor-compatible launcher follows the actual CDP port selected by the runtime after a restart instead of assuming port 9341.
- Restoring the original Codex appearance disables the relaunch monitor.
